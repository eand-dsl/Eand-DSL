<EN>
Icons ship **inside `@eand/react-design-system`** — there is no separate icons package.
They're synced from the
[etisalat App Icons](https://www.figma.com/design/9Q64oRPBkm3Sla5HMP4LJA/e--App-Icons?node-id=7-118)
Figma library. Every icon is a 24×24 glyph whose colours resolve to
`currentColor`, so it tints with the surrounding text `color`.

Each icon ships in two variants: **outline** (`bookmark`) and **filled**
(`bookmark-filled`). Use the toggle on a tile to preview either variant —
clicking the name copies the key for whichever variant is selected.

Icons are not mirrored for you. The library's own components mirror their directional
glyphs — chevrons, arrows — under `dir="rtl"`; when you place a directional icon
yourself, wrap it in `<span data-rtl-flip>` and it flips in RTL. Vertical glyphs such as
`chevron-down` never mirror.
</EN>

<AR>
تُطرح الأيقونات **داخل حزمة `@eand/react-design-system`** — فلا توجد حزمة منفصلة
للأيقونات. وهي مُزامنة من مكتبة
[اتصالات App Icons](https://www.figma.com/design/9Q64oRPBkm3Sla5HMP4LJA/e--App-Icons?node-id=7-118)
في Figma. كل أيقونة رسم بمقاس 24×24 تُستمد ألوانه من `currentColor`، فيتلوّن
بلون النص المحيط به.

تُطرح كل أيقونة بنمطين: **الإطار** (`bookmark`) و**التعبئة** (`bookmark-filled`).
استخدم مفتاح التبديل على أي مربّع لمعاينة أيّ من النمطين — والنقر على الاسم ينسخ
مفتاح النمط المحدّد.

لا تُعكس الأيقونات تلقائيًا. فالمكوّنات في المكتبة تعكس رموزها الاتجاهية — كالأسهم
مثل `chevron-right` و`arrow-left` — عند `dir="rtl"`؛ وإذا وضعت أيقونة اتجاهية بنفسك،
فضعها داخل `<span data-rtl-flip>` لتنعكس في الاتجاه من اليمين إلى اليسار. أما
الأيقونات الرأسية مثل `chevron-down` فلا تُعكس أبدًا.
</AR>

```tsx
import { Icon } from '@eand/react-design-system';

<Icon name="wallet" size={24} />
<Icon name="wallet-filled" size={24} />
```

<EN>
Descriptions and search aliases are synced from the icon library in Figma —
searching below matches names, descriptions, and aliases (try `flag`).
</EN>

<AR>
الأوصاف وأسماء البحث البديلة مُزامنة من مكتبة الأيقونات في Figma — والبحث أدناه
يطابق الأسماء والأوصاف والأسماء البديلة (جرّب `flag`).
</AR>

## V1.2 renames

<EN>
Figma DSL V1.2 gave the set's numbered duplicates real names and added `dot`, so the
code now matches Figma one to one: 198 icons, each outline and filled.
</EN>

<AR>
أعطى الإصدار 1.2 من نظام التصميم في Figma النسخَ المرقّمة المكرّرة في المجموعة أسماءً
فعلية، وأضاف `dot`، فصار الكود يطابق Figma تمامًا: 198 أيقونة، لكلٍّ منها شكل بإطار
وشكل بتعبئة.
</AR>

| V1.1 name | V1.2 name | Note |
| --- | --- | --- |
| `add-2` | `add` | The bare plus. |
| `add` | `add-content` | The circled plus. `add` now means the bare plus. |
| `copy-2` | `copy-doc` | |
| `grid-2` | `grid` | V1.1's asymmetric grid is gone. |
| — | `dot` | New. The status dot used by `StatusIndicator`. |

<EN>
`add-2`, `copy-2` and `grid-2` (and their `-filled` forms) still resolve through
`ICON_ALIASES`, but they are deprecated. `add` could not be aliased because its meaning
changed: if you used it for the circled plus, switch to `add-content`.
</EN>

<AR>
ما زالت الأسماء `add-2` و`copy-2` و`grid-2` (وصيغها `-filled`) تعمل عبر
`ICON_ALIASES`، لكنها مُهمَلة. أما `add` فلم يكن ممكنًا جعله اسمًا بديلًا لأن معناه
تغيّر: إذا كنت تستخدمه لعلامة الزائد داخل دائرة، فانتقل إلى `add-content`.
</AR>
