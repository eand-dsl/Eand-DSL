## Anatomy

- **Header** — `title` (`heading.lg`), optional `context` line (`body.md`, subtle), an optional
  `filterPill`, and a `trigger` (a `chevron` circle, a text `button`, or `none`). Toggle the whole
  header off with `showHeader={false}`.
- **Body slot** — `children` sit in a 16px-padded slot. The **`size`** axis reserves the row height
  so the card type fits:

  | size | slot height | fits |
  |------|-------------|------|
  | `xs` | 72px | list rows, action bars |
  | `sm` | 148px | quick-action tiles |
  | `md` | 224px | deal / new-on cards |
  | `lg` | 300px | plan / product cards |
  | `xl` | 452px | highlight banners |

- **`surface`** is `default` (grey `#f0f0f5`) or `inverse` (brand red, white text). Set `carousel`
  for a horizontal-scrolling body and `gradient` for a bottom scrim over highlight-style content.
