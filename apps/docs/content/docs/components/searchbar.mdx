## When to use

- **Use** above a searchable list, or as an add-on below the [TopBar](./topbar) title.
- **Use** [AISearch](./aisearch) for the “Ask etisalat” assistant entry point.
- **Don't use** for form fields — that is the [Input](./input).

`Searchbar` accepts every native input prop, plus `onMic` for the voice-search button.

## Design

Figma source: [Standard search — etisalat Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=28114-62804)

- 52px tall, `spacing/lg` (16) inline padding, `border-radius/6` (16), fill
  `surface/base/default`.
- 20px search and mic glyphs in 20px boxes; the mic is `text/brand/default`.
- Placeholder and value are `body/md`.
- Not yet built: the 1px stroke (bound to a remote foundation variable with no DSL token),
  the 16px gaps, and the typing and typed states.
