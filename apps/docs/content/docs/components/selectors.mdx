  Figma DSL V1.2 publishes no segmented control. Its former Selectors page was renamed

  but its geometry is not checked against a published symbol.
</Callout>

<ComponentDemo id="selectors" />

## When to use

- **Use** to switch between two or three views of the same content in place.
- **Don't use** to choose a value the user will submit — use a [Picker](./picker) or
  [Radio](./radio) group. For views at page level, use [Tabs](./tabs).

## Design

There is no V1.2 symbol. The track is `surface/base/default` with a 2px inset; the active
segment is `surface/canvas/default`; segments are 36px tall with `spacing/md` inline padding
and `button/sm` labels.

The related Figma page: [Pickers — etisalat Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=28278-1530)
