  The AI Search frames in Figma DSL V1.2 are not finalised and have no published symbol.
  Until they are, `AISearch` is the [Searchbar](./searchbar) with the placeholder
  “Ask etisalat or search”.
</Callout>

<ComponentDemo id="aisearch" />

## When to use

- **Use** as the entry point to the etisalat assistant, where a query may be a question as well as
  a search.
- **Don't use** for plain search — use the [Searchbar](./searchbar).

`AISearch` takes the same props as `Searchbar`: every native input prop, plus `onMic`. The
site's [Finder](/finder) is a documentation feature built for this site, not this component.

## Design

Figma source: [AI Search component — etisalat Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=30635-82333)

- Frames only: a 367×396 card with a title row, a grid of suggestion chips or category filter
  pills, and a search field in default, focus and typing states.
- Voice dictation is drawn in three states: started (waveform and timer), transcribing and
  result.
- None of this is built yet; the component keeps the Searchbar geometry (52px,
  `border-radius/6`).
