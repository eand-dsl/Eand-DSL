## When to use

- **Use** for a single show-and-hide group inside a form or a detail page, where a flat row
  with a divider suits the layout.
- **Don't use** for a list of questions and answers; that is [FAQ](./faq). Not for navigation
  (use [ActionBar](./actionbar)) or for content the user always needs to see.

## Anatomy

- **Header** — a full-width button with the `title` in `title/sm` and a 16px `chevron-down-sm`
  that turns 180° when the row opens. It sets `aria-expanded`.
- **Content** — `children`, rendered only while open, with 12px below.
- **Divider** — a 1px bottom border in `border/surface-based/raised/default`.

The row manages its own state; `defaultOpen` sets the initial state.
