## When to use

- **Use** to show where the user is in a multi-step flow. The [TopBar](./topbar) uses it as
  its `.topbar-stepper` bottom element.
- **Use** `inverse` on brand-red and midnight surfaces.
- **Don't use** for a continuous quantity — use [ProgressBar](./progressbar) or
  [PlanUsageBar](./planusagebar).

`steps` is clamped to 2–8, as Figma defines it, and `progress` (the completed segments) to
0–`steps`.

## Design

Figma source: [stepper — etisalat Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=32960-73561)

- A 6px row of equal-width pill segments (`border-radius/9`), spaced by `spacing/xs` (4px).
- Colours are `stepper/{default,inverse}/{default,selected}`: completed segments take
  `selected`, the rest `default`.
- The `stepper-rtl` set is a mirror; the row follows the document direction.
