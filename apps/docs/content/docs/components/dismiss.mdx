## When to use

- **Use** to close or remove something in place: a sheet, a banner, a tooltip. The library
  uses it for the removable [Chip](./chip) and for clearing an [Input](./input).
- **Use** `surface="inverse"` on dark surfaces.
- **Don't use** for back navigation — that belongs to the [TopBar](./topbar).

The accessible name defaults to “Dismiss”. Pass `aria-label` when the context needs a more
specific one, such as “Remove filter”.

## Design

Figma source: [dismiss — e& Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=28961-19839)

- `md`: a transparent 24px box (`icon/xl`) with a 2px inset (`spacing/2xs`) holding a 20px
  `dismiss-filled` glyph. `sm` (Figma `small`): a 20px box with a 16px glyph.
- Ink `color/dismiss/default` or `color/dismiss/inverse`. The X is knocked out, so the
  surface shows through; it is not white.
- Figma still instances a legacy local close icon of the same geometry; the code uses the
  icon set's `dismiss-filled`.
