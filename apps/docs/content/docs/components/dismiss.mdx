## Design

Figma source: [Dismiss — e& Consumer App DSL V1.1](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.1?node-id=28961-16066)

Notes from the Figma spec:

- Circular button; filled in the `color/dismiss/*` value with a white X.
- Surface **default** (`#908e9a`) for light backgrounds, **inverse** (`#c0bfc8`) for dark.
- Size **md** = 24px, **sm** = 20px. The dismiss colors aren't in the exported
  `variables.json` yet, so the component carries the live Figma values.
