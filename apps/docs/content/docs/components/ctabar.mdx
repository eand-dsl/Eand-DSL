## When to use

- **Use** at the bottom of a purchase, checkout or confirmation screen, to hold the screen's
  committing action together with what the user is committing to.
- **Don't use** for actions inside the page — place a [Button](./button). Not for a compact
  inline action row ([ActionBar](./actionbar)) or for app navigation ([NavBar](./navbar)).

## Anatomy

`CtaFooter` is Figma's `cta-bar`: a surface, an [ActionBlock](./actionblock) and the iOS home
indicator. The action block stacks its slots top to bottom:

1. **`ribbon`** — a full-bleed `StatusRibbon`: `success`, `alert`, `warning` or `info`.
2. **`price`** — rendered as a [PriceLine](./priceline):
   `{ label, value, actionLabel?, onAction?, actionIcon? }`. `note` is deprecated.
3. **`terms`** — a [ConsentCheckbox](./consentcheckbox). Pass it controlled, so its state
   stays with you.
4. **`payment` + `actions`** — with a `PaymentRow`, the payment method and the confirm button
   take half the width each. Without one, `actions` (a `ButtonGroup` or a block `Button`)
   spans the bar.
5. **`homeIndicator`** — on by default. It is also the bar's only bottom spacing, so leave it on.

`surface={false}` drops the white card and shadow, for a bar that sits on a surface which
already separates it. `rounded={false}` squares the top corners.

```tsx
<CtaFooter
  price={{ label: 'Total', value: 'AED 120.00' }}
  terms={
    <ConsentCheckbox
      checked={agreed}
      onChange={(e) => setAgreed(e.currentTarget.checked)}
      prefix="Agree to the"
      links={[{ label: 'Terms' }, { label: 'Privacy Policy' }]}
      suffix="before proceeding"
    />
  }
  actions={<ButtonGroup primary={<Button size="lg" block disabled={!agreed}>Confirm</Button>} />}
/>
```

`ButtonGroup` stacks buttons 20px apart, or with `orientation="horizontal"` puts secondary and
primary side by side, 12px apart (secondary first). A tertiary action always sits on its own
centred row.

## Design

Figma source: [cta-bar — etisalat Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=31617-1007)

- Top corners `border-radius/8` (24). Surface `surface/base/inverse` with `shadow/md`
  (0 0 44 0, midnight at 10%).
- Action block padding: 16/20/0/20 for the checkbox line; 20/20/0/20 for the actions, or
  16/20/0/20 beside a payment method, with a `spacing/2xs` gap.
- Status ribbon: 40px (`scale/40`), padding 4/20, `alert-message/{surface,text}/<status>`, a
  24px icon box and a `title/xs` label. Its action is `body/md` in
  `button/link/text/midnight/default`.
- Payment row: a 40px tile at `border-radius/3`, a `body/md` label, and “Change” as a tertiary
  `md` button.
- Home indicator: a 34px block with a 144×5 bar 8px from the bottom. The bar uses the iOS
  kit's black `Labels/Primary`, which is not a DSL token.
- Every row mirrors in RTL.
