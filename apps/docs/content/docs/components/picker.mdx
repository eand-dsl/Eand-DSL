## When to use

- **Use** to choose one value from a small set shown side by side, such as top-up amounts.
  `Picker` manages the selection; `PickerOption` is the standalone tile for custom layouts.
- **Don't use** for a long list — use an [Input](./input) of `type="dropdown"`. For options
  that combine, use [Checkbox](./checkbox); to switch views, [Tabs](./tabs).

## Anatomy

- **Value** — `title/sm`, centred. **Caption** — `body/xs` beneath it, such as a unit.
- **Badge** — a string or number renders the neutral `sm` status [Badge](./badge) as a strip
  along the bottom of the tile. Any other node renders as given. Hidden while disabled.
- **Selected** — the fill and ink swap, and a check circle appears at the top end. On `default`
  and `light` the tile turns midnight with white text; on `inverse` and `glass` it turns white.
- **Disabled** — disabled ink, no badge. A disabled tile never shows as selected.

The `surface` names predate V1.2 and map to Figma's surfaces as follows:

| `surface` | Figma surface | Tile fill |
| --- | --- | --- |
| `default` | sunken | `surface/sunken/default` |
| `light` | default | `surface/canvas/default` |
| `inverse` | midnight | `surface/raised/midnight` |
| `glass` | glass | `surface/glass/white/lg` |

## Design

Figma source: [picker — etisalat Consumer App DSL V1.2](https://www.figma.com/design/pzm63BTLfPfT1stcF89ILQ/e--Consumer-App-DSL-V1.2?node-id=34373-16787)

- A fixed 106×72 tile (`scale/72`), `border-radius/6` (16), content centred with 20px top
  and 8px side padding.
- Selected, default scheme: `surface/raised/midnight` with `text/default/inverse`. Inverse
  scheme: `surface/raised/default` with `text/default/default` and `subtle`.
- The check is `check-circle-filled`, 20px in a 24px box, 6px from the top and end edges.
- Badge strip: a 2px inset and corner radii 6/6/28/28, so the strip follows the tile's curve.
  The bottom 28 has no token.
- Glass: `surface/glass/white/lg` behind a 20px backdrop blur.
