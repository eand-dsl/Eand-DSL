## When to use

- **Use** for the determinate progress of a single quantity, on a surface that already frames
  the bar. `value` runs from 0 to 100 and is clamped.
- **Don't use** for a plan allowance — that is [PlanUsageBar](./planusagebar). Not for the
  steps of a flow; use [Stepper](./stepper).

The bar has no track of its own, as in Figma. Pass `style` to add a background if a surface
needs one. `tone` (`accent`, `positive`, `warning`, `danger`) is a code-only override; Figma
publishes the green fill only.

## Design
