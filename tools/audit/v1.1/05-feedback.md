### Plan Usage Bar — `26663:89880`
- Page is unflagged (name " ↳ Plan Usage Bar "); single section "Component name" 29052:2711 with component board 29052:2737 + Statesheet 29670:8289.
- **V1.1 anatomy is a filled block bar, not a labeled thin bar.** `.plan-usage-bar` **28927:23669** (295×48): container bg `color/surface/canvas/inverse` #f7f7fa, radius `border-radius/3` 12px, overflow-clip; inside it a `progress-bar-core` whose `bar` fill is `color/green/550` **#54bc72** anchored left (same radius). All text sits **on top of the bar** in a 36px-high px-16 overlay row: left `.plan-usage/value` = "2" + "GB" + "left" (`typography/title/xs` Suisse SemiBold 14, lh 1.3, color `button/text/midnight/default` #191329) with optional `.plan-usage/content` second line ("Expires 3 days", `body/sm` 12); right `.plan-usage/label` ("Local Data", `button/md` Medium 14, `text/action/midnight/default`).
- `.progress-bar-status` **28927:22814**: axis `Progress status` = Default (fill `green/550` #54bc72) | **low data** (fill `color/orange/500` **#ff9f52**). Only two statuses exist.
- Statesheet 29670:8289 rules: variants = Default + "Low data warning"; *"Normal: data levels above 30% remaining"*, *"Warning: plan expiring within 3 days or below 30%"*; anatomy note: *"Plan-usage width is decided by the section container. should always be set to 'Fill' inside a section"*. States notes describe the template: filter tabs switch usage category, All selected by default, *"The action bar appears when any plan is critically low or expired."*
- **Code drift:** `PlanUsageBar` renders label + "used / total GB" text *above* the shared `ProgressBar` primitive (8px pill, red default — itself already flagged in 01-primitives) and derives three tones from % *used* (≥90 danger, ≥75 warning, else accent). Figma semantics run on data *remaining* ("2 GB left"), have exactly two visual states, and put all type inside the 48px bar. Anatomy, thresholds, token bindings and value semantics all differ.
- Composition gap: `.usage-bar-set` **29277:2351** (plans=2/3/low data warning/4+, 295×152) and the `Plan usage` template **29222:13753** (319×300: chips All/Data/Talk/Roam + stacked bars + action-bar with red CTA — screenshot verified) have no code counterpart. MISSING-IN-CODE, document only.
- `plan-usage-bar.md` is current (all axes/dims verified live); design.md §Plan Usage Bar "States: usage level: normal / warning / danger" is stale V1.0-style language vs the 2-state V1.1 spec.
