### Colors — page `25460:22588`
Page structure: `Colours` primitives frame **25541:33328** (3948×14825), `Colours` 26608:535632, section `Surface system` 27131:101371, `Colours/surfaces` 28165:42785, and the master semantic reference `Color Token Documentation — Detailed — tokens` **29626:329310** (6757×21558).

**Method:** `get_variable_defs` on 29626:329310 returned **293 live semantic color tokens**; on 25541:33328 returned the full primitive ramps + additional families. Compared against `variables.json` (flattened: 830 tokens total, 296 in `tokens/color`, 147 in `primitives/color`) and `tokens.css` (830 vars, `--eand-*`). Alpha comparisons tolerance-normalized (e.g. Figma `#…4d` ≡ css `rgba(…, 0.30)` — not drift).

**Brand anchors verified:** `color/red/1000` = **#e00800** ✓ · `color/midnight/1000` = **#191329** ✓ (both live and in export). Light-only system confirmed — `inverse/*` tokens are on-dark content colors, no dark-mode collection.

#### B. Renames / new tokens in Figma missing from the export (13 semantic + 2 primitive + alert-message 8)
- **Chips rename:** live `color/chips/default/outline/{surface/focus, text/default, text/focus, text/disabled, border/default, border/focus, border/disabled}` — export still has these under `color/chips/default/default/*`. Same values except text/focus above.
- **Input-field additions:** `color/input-field/text/default/value/filled` #191329, `…/value/error-filled` #191329, `…/value/error-empty` #575362, `color/input-field/surface/default/active` #ffffff, `…/filled` #ffffff, `…/error` #ffffff. Export instead carries stubs `color/input-field/text/default/Color` and `…/inverse/Color` that no longer appear live.
- **New primitive steps:** `color/green/550` #54bc72 and `color/orange/550` #fa700c (live only). green/550 duplicates green/600's hex — likely inserted so aliases can re-point later.
- **`color/alert-message/*`** (8 tokens, values in drift table) — confirmed **zero** occurrences in variables.json/tokens.ts/tokens.css. This is the family 05-feedback.md flagged; its absence dates the export to before the alert-message "Final component" work.
- Oddity live in Figma: `color/status/positive/positive 2` (#3b8b53) — junk duplicate variable nested under a token leaf; flag to design for deletion.

#### C. Families live in Figma but absent from variables.json — likely OLD-generation variables still bound in legacy doc sections (verify before exporting)
Sampled on the big `Colours` frame 25541:33328, which retains deprecated sections:

- Flat `color/border/{default, subtle, strong, focus, disabled}` + `color/border/solid/*` + `color/border/{positive, warning, danger}` + `color/border/inverse/*` (superseded by `border/interactive/*` + `border/surface-based/*` which ARE in the export)

#### D. Confirmed non-drift
Everything else in the 293-token semantic sample matches the export exactly, including: full `surface/*` (canvas/base/sunken/raised/overlay/glass), `text/*` (default/brand/positive/danger/warning), `border/interactive/*`, `button/{primary, secondary, tertiary, link, text-midnight}`, `tab/*`, `filter-pill/*`, `status/*`, `badge/*` (incl. tiers), `mark/*`, `atom-surfaces/*`, `navbar-tab/*`. Known Figma naming quirks that survive round-trip: `color/badge/surface/offers/limited stock` (space) and `color/border/surface-based/overlay/floating inverse` (space) — build-tokens normalizes both to dashes in CSS, but `tokens.ts` still carries the `"limited stock"` key bug (see 01-primitives.md).
